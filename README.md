# Пульт Saltic на ESP32

Маленький пульт на экранчике SSD1306 128×64, написанный на
[Saltic](https://github.com/zephyr-m) от первого байта до последней точки:
ни прошивки Espressif, ни чужих библиотек. Первая программа Saltic со своим
репозиторием — экран и шину она получает пакетами через **tarantul**.

```
ПУЛЬТ                          03:12
· · · · · · · · · · · · · · · · · ·
┌ СИСТЕМА ─────┐  ┌ КАДРЫ ────── 37 ┐
│ куча 21К     │  │                  │
│ ▓▓▓▓▓░░░░░░  │  │   ▌▌▌▌ ▌▌▌▌▌▌▌▌ │
│ 160 МГц      │  │   ▌▌▌▌▌▌▌▌▌▌▌▌▌ │
│ I2C ок       │  │   ▌▌▌▌▌▌▌▌▌▌▌▌▌ │
└──────────────┘  └──────────────────┘
```

Всё на экране живое: время работы платы, занятая куча программы, кадров в
секунду и столбики за последние 14 секунд.

## Железо

- плата ESP32 DevKit (ESP32-D0WD), кварц 40 МГц;
- экран SSD1306 128×64 на I2C, адрес 0x3C: SDA — D23, SCL — D22, VCC — 3V3;
- кабель USB, плата видна как `/dev/ttyUSB0`.

## Как собрать

Нужен склонированный Saltic (Linux x86-64), `just`, `git`, для прошивки —
`nix-shell` с `esptool`. Дом Saltic — переменная `SALTIC_HOME`, по умолчанию
`~/dev/rnd/saltic`.

```
just          # собрать инструменты Saltic, привезти пакеты, собрать build/pult.bin
just flash    # то же и залить на плату
```

`just` сам зовёт `tarantul get`: пакеты из `tarantul.json` (по замку
`tarantul.lock`) ложатся в `tarantul/` — в git их нет.

## Устройство

Субъектный стиль: каждый блок экрана — Box в своём файле и рисует себя сам.

| файл | что это |
|---|---|
| `console.saltic` | `Pult { sheet, top, left, right }` — холст и три блока; `step()` — кадр |
| `canvas.saltic` | `Canvas` — кадр 128×64 в арене: точки, рамки, текст Spleen 5×8, отправка на экран |
| `head.saltic` | `Head { seconds }` — «ПУЛЬТ» и время работы |
| `system.saltic` | `System` — куча с полоской, частота ядра, шина |
| `frames.saltic` | `Frames` — кадров в секунду и столбики, сам считает секунды |
| `tarantul.json` | пакеты: `ssd1306` (по зависимости приезжает `i2c_esp32`) |

## Известное

- Нынешний компилятор Saltic собирает для ESP32 образ, который падает с
  `IllegalInstruction`: код перерос 128 КБ и залез за `0x400A0000`. Пока не
  починено, на плату пульт уходит сборкой компилятором до новой модели памяти
  (Saltic `b4499ec`).
- Запас и там почти кончился: код кончается на `0x4009fbf0`.
- «160 МГц» и «I2C ок» не меряются на ходу: частоту ставит платформа при
  старте, а без ответа экрана пульт не запускается вовсе.
